# NOS3 Common Terminology

| Term                         | Plain-language definition                                                                                                                                                                                                          |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| NOS3                         | A spacecraft development and test environment that connects flight software, simulated hardware, ground software, and dynamics/environment models. It is a collection of cooperating tools, not just one satellite simulator. nos3 |
| Flight software (FSW)        | Software that performs spacecraft functions: processing commands, collecting data, controlling devices, and reporting status. In NOS3, it can run against simulated hardware. nos3                                                 |
| cFS                          | Core Flight System: a reusable flight-software architecture with applications and common services. It is a flight-software framework, not the entire NOS3 environment. nos3                                                        |
| Flight-software application  | A software unit within the flight-software system that performs a particular function and can handle commands and produce telemetry. github                                                                                        |
| Ground software              | The tools used outside the spacecraft to send commands and receive/display telemetry. COSMOS is the ground-software tool used in the documented NOS3 architecture. nos3                                                            |
| Component simulator          | A program that imitates a hardware device’s interfaces and behavior so flight software can interact with it without the physical device being present. nos3                                                                        |
| NOS Engine                   | Middleware that provides simulated communication buses and supports coordinated simulation time. It connects participating software; it is not itself the spacecraft dynamics model. nos3                                          |
| Hardware abstraction / HWLIB | The layer through which flight software accesses hardware interfaces. In NOS3, those accesses can be connected to simulated devices instead of physical ones. nos3                                                                 |
| 42                           | The dynamics/environment simulator used by NOS3 to calculate spacecraft motion and environmental information needed by relevant component simulations. nos3                                                                        |
